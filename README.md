# 📄 Hoja de Vida — Luis Carlos Taborda Flórez

Página web estática que presenta mi hoja de vida de forma moderna y responsiva, construida con **HTML** y **Tailwind CSS**.

## 🚀 Demo en vivo

🔗 [hoja-de-vida-virid.vercel.app](https://hoja-de-vida-virid.vercel.app)

## 📁 Repositorio

🐙 [github.com/TABORDA1234/hoja-de-vida](https://github.com/TABORDA1234/hoja-de-vida)

## 🛠️ Tecnologías

- **HTML5** — Estructura semántica
- **Tailwind CSS** (v3 CDN) — Estilos y diseño responsivo
- **Google Fonts** (Inter & Outfit) — Tipografía moderna
- **Font Awesome** — Íconos
- **Vercel** — Despliegue

## ✨ Características

- Diseño responsivo (mobile, tablet, desktop)
- Tarjetas con animaciones hover
- Secciones: perfil, experiencia, educación, formación, skills e idiomas
- Paleta de colores profesional en tonos azules
